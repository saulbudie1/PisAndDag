# Pistols and Daggers — Wiki

The player-facing wiki for the mod: what things are, how to get them, what they do.
Kept out of the built mod (`build.txt` buildIgnore: `wiki\*`).

## Layout

- `README.md` — this page: the index.
- One Markdown page per subject, named as the thing is named in game (`Dented_Megashark.md`, `Skeletron.md`).
- `images/` — screenshots and sprites the pages show.
